# Scroll Saw Studio / 细锯工坊

Play: https://335083474.github.io/scroll-saw-play/

Version 0.3: eight original patterns, gradual paper peeling to reveal wood grain, a browser-local finished-work shelf, and a three-piece bear puzzle with cutting and drag-to-assemble stages.

Drag with one finger from either side. Use two fingers together to move or rotate the board and pinch to zoom. Lift your fingers to stop. Open 图案册 to choose a pattern. After cutting, reveal the wood and save your finished work to 成品架. The shelf keeps up to 24 works in this browser; clearing site data removes them.

This repository contains built web assets for GitHub Pages. The development source is maintained separately in a private repository. No source maps are published. JavaScript required to run the game is delivered to the browser. Previous runtime assets are retained for cached pages during updates.
