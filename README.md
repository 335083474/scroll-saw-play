# Scroll Saw Studio / 细锯工坊

Play: https://335083474.github.io/scroll-saw-play/

A mobile-first 3D scroll saw game. Drag with one finger from either side. Use two fingers together to move or rotate the board and pinch to zoom. Lift your fingers to stop. Camera views and a full cutting demonstration are available in the bottom toolbar.

This repository contains built web assets for GitHub Pages. The development source is maintained separately in a private repository. No source maps are published. JavaScript required to run the game is delivered to the browser.
